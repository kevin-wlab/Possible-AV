# ops-log/ — session logs, context and progress

Agent working notes. No site content lives here.

| File | What it is | When to update |
|---|---|---|
| `CONTEXT.md` | Owner rules, positioning, IDs | When a rule changes |
| `PROGRESS.md` | What's done/live, open items, next steps | End of every session |
| `sessions/YYYY-MM-DD-<topic>.md` | One file per session | New file each session |

This repo is public — see the rules in the root `CLAUDE.md`.
