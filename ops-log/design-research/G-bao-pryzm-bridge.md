# Teardown G — byassociationonly.com, pryzm.design, bridgemoney.co (sub-agent report, condensed)

## By Association Only — editorial luxury agency (Webflow), ~12.3k px
- Fixed transparent nav (hides on scroll down, returns on scroll up) → near-empty #181818 hero with ONE H1 bottom-right (ITC Galliard 40px, one italic phrase) → FULL-BLEED SHOWREEL video already peeking on first screen, circular rotating-text "play reel" badge → PINNED HORIZONTAL-SCROLL case studies: 5 tall (~45vw × 85vh) autoplay video cards, serif title + 2-line description + "• View case study" bottom-left, ends with rotating "VIEW ALL CASE STUDIES" badge → GIANT SERVICE-NAME LIST (86px serif) that lights up grey→white as each name crosses the reading line, sticky explainer + "View services" on right → 5×9 monochrome CLIENT LOGO WALL on hairline rows → content bento (award article / e-book / podcast) → newsletter strip with big serif values line + rotating monogram → minimal 4-col footer with italic labels.
- Colour: #181818/#000, white, hairlines 5–8%; no accent. ~30px edge padding, 200–300px section gaps, 0–2px radii.
- Borrow: restrained hero line → full-bleed sizzle reel of real installs/events; pinned horizontal case-study gallery with autoplay video cards + city/venue tag; giant scroll-lit service list (AV Systems / Projection / Audio / Network / Interactive / Experiential) with sticky explainer; hairline logo wall (clients/venues — only if owner approves names; owner rule: no client names → likely skip or use venue types); bento for spec sheet / capability deck / BTS video; one rotating text badge. Don't: all-serif luxury tone, buried Contact.

System from Pryzm (black, mono captions, media-tinted glowing cards, signal-flow node graph, eyebrow/H2/button template). Energy from Bridge (rotating hero word, one signal accent, gear renders over type, project ticker, count-up stat, giant wordmark footer). Plus a persistent "Request a quote" button and travel/city proof throughout.
