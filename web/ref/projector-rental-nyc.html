Questions

Projector rental, briefly.

How bright a projector do I need?

It depends on the image size and how much light is in the space. For lit spaces and large screens we use Epson laser projectors up to 7,000 lumens; tell us the space and we will spec it.

Do you rent a projector with a screen?

Yes. Projectors go out with the screen, stands or rigging, cabling and playback the job needs.

Can you project on a building or an object?

Yes. Projection mapping on walls, objects and irregular surfaces is part of our projection work.

Is setup included with a projector rental?

Yes. We deliver, set up, focus and test it, and a technician can stay to run it.

Do you install home theater projectors?

Yes. We rent projectors for home use and install home theater systems in New York.
