Questions

Event Wi-Fi, briefly.

Why not use the building Wi-Fi?

You cannot control it or see into it, and it is shared with everyone else. When streaming, check-in and payments depend on it, a network of your own is safer.

Can you provide internet for an event?

We plan the internet connection with the space, add a backup path, and build the Wi-Fi and wired network on top.

Do you install permanent networks?

Yes. UniFi networks for offices and buildings, with structured cabling and support.

Is someone on site during the event?

Yes. The network is monitored while the event runs, with a technician on hand.
