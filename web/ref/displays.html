Questions

Displays, briefly.

Can a touch screen run our own app?

Yes. Touch screens have Android or Windows built in and run your app, or one we build for you.

Do you sell screens, or only rent them?

Both. Screens can be rented for an event, bought, or installed permanently.

Do you put up LED walls?

Yes. LED video walls go up with the same crew. Sizes, specs and pricing are on our LED site, ledwall.nyc.

Do you work outside New York?

Yes. We are based in Brooklyn, New York, and the same crew travels with the equipment.

What if we need something you don't list?

Ask. If we don't carry it, we source it and make it work with the rest of the system.
